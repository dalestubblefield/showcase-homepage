# Showcase Homepage

A cool homepage for your ServiceNow instance as well as some custom menus.

## Prerequisites

Before installing this application, you must first import the **Showcase Homepage Global Utils** app into your instance via Studio.

1. Open Studio on your ServiceNow instance (`/nav_to.do?uri=studio.do`)
2. Click **Import From Source Control**
3. Import from: `https://github.com/dalestubblefield/showcase-homepage-global-utils`
4. Complete the import and close Studio

This dependency provides global utilities required by the homepage application.

## Installation

Import this application into your instance using the same Studio process:

1. Open Studio on your ServiceNow instance
2. Click **Import From Source Control**
3. Import this repository
4. Complete the import
